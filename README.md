# CYBER ARMY for Termux

A colorful Termux startup banner with an ANSI art image, a rainbow `CYBER ARMY` title, and a prompt whose color changes (colors 1-255) with every command.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/USERNAME/cyber-army/main/install.sh | bash
```

Then close Termux and open it again.

## Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/USERNAME/cyber-army/main/uninstall.sh | bash
```

## What it does

- Installs `ruby`, `figlet` and `lolcat`
- Creates `~/banner.sh` and `~/banner_img.ans`
- Adds the banner and the colorful prompt to `~/.bashrc`

## فارسی

برای نصب، دستور بالا را در Termux اجرا کن و بعد Termux را ببند و دوباره باز کن.
به‌جای `USERNAME` اسم کاربری گیت‌هاب خودت را بنویس.
